# Surface brief

Mode: operate. Scope: public interface and its subordinate routes. User delegated design choices and removal of unfinished presentation work. Code-led implementation tests the actual interaction.

## Direction contract

THESIS: A tool preview desk. Reject duplicated promotional sections and card walls.

OWN-WORLD: Exact Radix colors with semantic steps, four or fewer text sizes, 0.5px borders, minimal radii and no decorative shadows. Original screenshots and game assets remain content.

STORY: Selecting a tool changes the preview. Search, tags, deterministic shuffle and shareable URL retain real catalog data. Mobile uses a horizontal collection strip.

FIRST VIEWPORT: Search and category controls above a 280px collection list and persistent selected preview.

FORM: Content-specific working surface; user-directed functional redesign. seed:559eeba5fc6788fa. Palette and low-motion constraints override catalog material treatments.
